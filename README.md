# PIXORA PHOTO EDITOR — v1.0 starter project

PIXORA is a Flutter mobile photo editor starter application. This source includes a working first version of:
- Gallery image selection
- Live brightness, contrast and saturation preview
- Rotate image
- Reset adjustments
- Export processed JPEG to the device gallery
- Dark and light theme toggle

## Important scope note

This is the first working MVP, not the entire feature list originally discussed. Crop, filters/presets, collage, text/stickers, AI background removal, object removal, restoration, and advanced export formats are not implemented in this v1.0 starter. They should be added and tested in later releases. Do not advertise them as available until implemented.

Basic editing and export are designed to work offline after installation. The app does not require sign-in and does not upload selected photos to a server.

## Build APK without owning a computer

This project includes a GitHub Actions workflow.

1. On your Android phone, open https://github.com and create a free account or sign in.
2. Create a new repository named `pixora-photo-editor`. Set it to **Public** or **Private**.
3. Download and extract this ZIP on your phone if your file manager supports ZIP extraction.
4. In the repository, use **Add file → Upload files** and upload the project files and folders. Make sure `.github/workflows/android-apk.yml` is included. GitHub's mobile website may hide dot-folders; if so, use GitHub's browser desktop-site mode or upload the project using a Git client app that supports folders.
5. Commit the files to the `main` branch.
6. Open the repository's **Actions** tab. Select **Build PIXORA Android APK**, then tap **Run workflow** if it has not started automatically.
7. Wait for the workflow to finish. Open the successful run and scroll to **Artifacts**.
8. Download `PIXORA-Photo-Editor-Android-APK`. Extract the downloaded artifact ZIP; inside is `app-release.apk`.
9. Open the APK on your Android phone and approve installation from that source if Android asks. Only install APKs built from your own repository/workflow.

## Local build (if you later have a computer)

Install Flutter SDK and Android Studio, then run:

```bash
flutter pub get
flutter analyze
flutter build apk --release
```

APK output:
`build/app/outputs/flutter-apk/app-release.apk`

## iOS

The included `ios-build.yml` runs on a macOS GitHub runner and can compile an unsigned iOS build. Installing and distributing an iOS app requires Apple signing credentials, certificates/provisioning, and usually an Apple Developer account. An unsigned build is not installable as a normal App Store app.
